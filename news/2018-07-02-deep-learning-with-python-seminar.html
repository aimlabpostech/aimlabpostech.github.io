Deep Learning with Python Seminar

Following the Deep Learning seminar held in the spring semester of 2018, a seminar on implementing deep learning directly with Python will be held in the summer of 2018.

Building on an understanding of deep learning, this seminar aims to deepen the participants' understanding of both deep learning and Python through hands-on practice with Python.

All members of the AIM Lab take part in the seminar, which runs for one month starting July 2, 2018. Participants study together and share their views by researching, organizing, and presenting textbook material and literature.

The textbook used is DEEP LEARNING with Python (Chollet).

Deep Learning with Python 세미나

2018-1학기 Deep Learning 세미나에 이어, 2018 하계에는 Python을 이용하여 직접 Deep Learning을 구현해보는 세미나를 진행합니다.

이번 Deep Learning 세미나는 Deep Learning에 대한 이해를 바탕으로 Python을 이용해 직접 실습해봄으로써 Deep Learning과 Python에 대한 이해의 깊이를 더하고자 합니다.

세미나는 저희 AIM 연구실 구성원 모두가 참여하며, 2018년 7월 2일부터 한 달간 진행되고 교재 및 문헌을 조사/정리/발표하여 함께 공부하며 의견을 공유합니다.

교재로는 DEEP LEARNING with Python(Chollet.)을 사용합니다.

Originally published on the AIM Lab board on 2018.07.02.
