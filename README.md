# aimlabpostech.github.io

Homepage of the **Analytics & Information Management (AIM) Lab**, Department of Industrial &
Management Engineering, POSTECH.

- Live site: <https://www.analyticsim.org>
- GitHub Pages origin: <https://aimlabpostech.github.io>

## How the site is built

Plain static HTML, CSS and a small amount of JavaScript. No frameworks, no build step required to
deploy — GitHub Pages serves the `.html` files in the repository root as they are.

```
index.html            Home
research.html         Research areas and application domains
people.html           PI, graduate students, alumni
publications.html     Journal articles and international conference papers
projects.html         Selected projects, research centers, partners
news.html             News and events
join.html             Recruiting information
contact.html          Address and directions
404.html              Not-found page

assets/css/style.css  All styling
assets/js/main.js     Mobile navigation, publication filters
assets/img/           Favicon and images
CNAME                 Custom domain (www.analyticsim.org)
.nojekyll             Serve files as-is, skip Jekyll processing
sitemap.xml           Generated
```

## Editing

**Small text change:** edit the `.html` file directly and commit. That is all it takes.

**Structural change** (navigation, footer, a new page, the publication list): the HTML files are
generated by `_build/build.py`, which keeps the header, navigation and footer identical across
pages. Edit the content lists at the top of that script — or the citation files in `_build/data/` —
and regenerate:

```bash
python3 _build/build.py
```

It has no dependencies beyond the Python standard library and rewrites every `.html` file in the
repository root. If you edit an `.html` file by hand and later run the script, your hand edit is
overwritten — put lasting changes in `build.py`.

### Adding a publication

Append the citation to `_build/data/journals.txt` or `_build/data/conferences.txt` in the same
format used by the existing entries:

```
Lee, D., Song*, M., & van der Aalst, W. M. P. (2026). Title of the paper. Journal Name, 164, 102601.
```

Then run `python3 _build/build.py`. Entries are grouped and sorted by year automatically.

### Adding a person or a news item

Edit the `STUDENTS`, `PHD_ALUMNI`, `MS_ALUMNI`, `NEWS` or `PROJECTS` lists in `_build/build.py`
and regenerate.

### Adding the PI photo

Drop a square image at `assets/img/minseok-song.jpg` and replace the `<div class="pi-photo">MS</div>`
placeholder in `build_people()` with `<img class="pi-photo" src="assets/img/minseok-song.jpg" alt="Minseok Song">`.

## Custom domain

`CNAME` pins the site to `www.analyticsim.org`. The DNS records for `analyticsim.org` must point at
GitHub Pages:

| Host  | Type  | Value                                                     |
| ----- | ----- | --------------------------------------------------------- |
| `@`   | A     | `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` |
| `@`   | AAAA  | `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153` |
| `www` | CNAME | `aimlabpostech.github.io.`                                |

Do not delete `CNAME`; removing it drops the custom domain from GitHub Pages.
